# INIFF RECOMBINANT GENOMICS (IR)

A **React + TypeScript** web application built with **Vite**, deployed on **Vercel**.  
This project provides an interactive, efficient, and modular front-end experience for recombinant data visualization and analysis.

🌐 **Live Demo:** [https://iniff-recombinant.vercel.app](https://iniff-recombinant.vercel.app)  
📦 **Repository:** [https://github.com/Inilogicz/INIFF-RECOMBINANT](https://github.com/Inilogicz/INIFF-RECOMBINANT)

---

## 🚀 Features

- ⚡️ Blazing fast builds with [Vite](https://vitejs.dev/)
- 💻 Fully typed using [TypeScript](https://www.typescriptlang.org/)
- 🧩 Modular and scalable React component structure
- 🎨 Easily customizable styling
- 🔁 Hot Module Replacement (HMR) for instant feedback during development
- ☁️ Deployed seamlessly on [Vercel](https://vercel.com/)

## 🛠️ Getting Started

### Prerequisites
Make sure you have **Node.js (v16 or higher)** and **npm** installed.

### Installation

```bash
# Clone the repository
git clone https://github.com/Inilogicz/INIFF-RECOMBINANT.git

# Navigate into the project directory
cd INIFF-RECOMBINANT

# Install dependencies
npm install

# Run Locally
npm run dev

# Build
npm run build
